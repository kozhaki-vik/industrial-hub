1. Principles of Operation

Industrial Hub is an open-source Windows desktop utility and community management tool designed to operate transparently and with minimal data collection. We respect user privacy and adhere strictly to data minimization:

  • No Personal File Inspection: The application does not scan, read, or upload personal documents, browser history, or user directories.
  • No Keystroke Logging: The application does not record or transmit keystrokes or input text. Shortcut listeners operate strictly as passive Windows hotkeys for display contrast toggling.
  • No Process Injection: The application does not attach debuggers, read foreign process memory, or inject DLLs into third-party games.
  • No Commercial Tracking: There are no advertising SDKs or third-party marketing trackers in the codebase.

2. Discord Bot Data Collection & Processing

When the Industrial Hub Discord Bot is invited to a server, it processes only the minimum data required for clan management and community automation:

  • Guild Identifiers: Server IDs, channel IDs, and role IDs to route tickets, assign roles, and log moderation events.
  • User Identifiers: Discord User IDs, usernames, and avatars for displaying dynamic clan rosters and leaderboard cards.
  • Voice Activity Metrics: Voice session timestamps (join/leave) and total minutes spent in non-AFK voice channels for clan participation statistics.
  • Recruitment Tickets: Content submitted voluntarily by recruits through modal application forms, and transcript logs for clan moderators.
  • Steam & Game Linking: Public Steam ID and hours played in Rust (only when voluntarily submitted via /link_steam).

The Bot does not read or record private Direct Messages (DMs) or chat messages outside of configured recruitment tickets and command interactions.

3. Desktop Client Telemetry & Diagnostics

  • Device Identifier: A locally generated installation UUID (stored in C:\ProgramData\IndustrialHub\device-id) is used solely to calculate active installations and maintain WebSocket state. It contains no hardware serial numbers or personal data.
  • Optional Diagnostics (Opt-In): With user consent, non-identifying environment data (CPU model, RAM amount, OS version) is collected for compatibility troubleshooting. This can be disabled at any time in Settings.
  • Crash Reporting: If an uncaught application error occurs, an anonymized error stack trace may be sent to our monitoring endpoint (/api/crash).

4. Data Storage and Security

  • Transport Security: All client-server-bot communications use encrypted TLS / WSS connections.
  • Access Control: Guild management actions require cryptographic token verification (clan_secret) and Discord administrator permissions.
  • No Third-Party Sharing: Collected data is never sold, leased, or shared with commercial entities.

5. User Rights & Data Deletion

Under Discord's Developer Policy and international privacy standards, users and server administrators have full rights to their data:

  • Bot Removal: Kicking or banning the Bot stops all data processing for your server.
  • Deletion Requests: To request complete deletion of any stored guild data, user stats, or ticket transcripts, open an issue on our GitHub repository.
